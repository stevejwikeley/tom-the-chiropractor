Foundations

The tokens in css/tokens.css that everything else is built from. Always reach for one of these instead of a hardcoded value.

Colour

Core palette, plus ink-at-opacity (for text/hairlines on light backgrounds) and cream-at-opacity (for text/hairlines on dark backgrounds).

Type scale

Font is Rubik throughout, weights 300–700. Each role below is a single shorthand token — use as font:var(--type-h2).

Spacing

Section padding and grid gaps, so spacing stays consistent section to section.

Buttons & links

Buttons are flat, square-cornered, uppercase, no exceptions. See design-system.md for the "no border-radius, no box-shadow" rule and its two narrow exceptions (small circular controls, floating chrome).

What is a chiropractor?

A chiropractor is a regulated healthcare professional who assesses and treats problems affecting the muscles, joints, nerves and spine.

Will it hurt?

Honestly, parts of it can be uncomfortable, but it settles quickly.
